# ML1 — Introduction to Machine Learning

Проект по введению в машинное обучение и анализ данных на Python.

## 📌 О проекте

В рамках проекта выполнялся анализ данных и знакомство с базовыми инструментами Machine Learning и Data Science.

Основной акцент сделан на:
- работе с датасетами
- preprocessing данных
- анализе признаков
- визуализации данных
- подготовке данных для ML-моделей

---

## 🚀 Реализованный функционал

- Загрузка и обработка данных
- Исследовательский анализ данных (EDA)
- Очистка данных
- Работа с признаками
- Визуализация распределений
- Анализ зависимостей
- Подготовка данных для обучения моделей
